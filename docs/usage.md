# 介绍与使用

本文按管理员第一次打开 Questra 到日常收集答卷的顺序说明功能。

## 1. 初始化站点

启动服务后打开 `/admin`。未初始化时会自动进入欢迎向导：

1. 创建管理员昵称、登录账号和至少 8 位密码。
2. 设置站点名称和可选图标。
3. 完成后使用账号密码登录后台。

每个数据库实例只有一组管理员账户。密码以带随机盐的 scrypt 哈希保存，不保存明文。登录会话默认有效 7 天；修改账号或密码会让现有会话失效。Admin Token 仍可作为兼容入口，但不应公开或写入代码仓库。

## 2. 认识三类对象

- **题库题目**：可编辑、可分组和反复使用的题目模板。
- **问卷/考试**：从题库生成的独立实例。
- **答卷**：填写者提交的一次结果。

生成实例时会复制题目标题、选项、必填属性、标准答案和分值，因此之后修改题库不会改变已发布实例或历史成绩。

## 3. 建立题库

在“题库”中添加单选、多选、判断或文本题：

- 单选、多选题至少需要两个选项；判断题固定为“正确/错误”。
- 通过“必填”控制是否允许空答案。
- 要创建考试，必须先为每道题设置标准答案；文本题可以设置多个可接受答案。
- 分组只是筛选和随机抽题工具，不是权限系统。删除分组不会删除题目或已经生成的实例。

建议在出题时同时确认题目文案、选项、是否必填和是否需要判分。题目更新不会回写到已经发布的实例。

## 4. 创建和发布问卷

在“问卷”中选择“普通问卷”或“考试”：

1. 填写标题、说明和可选截止时间。
2. 选择手动选题，或从全部题目/某个分组按题型随机抽题。
3. 如果是考试，选择计分方式并完成分值设置。
4. 保存实例，在列表中复制公开链接。

普通问卷不要求标准答案，也不返回分数。考试有两种计分方式：

- **满分与题型权重**：为每个出现的题型设置权重，总和必须为 100%，系统把满分按题型和题数分配到每题。
- **逐题分值累加**：为每道题设置正数分值，满分为所有题分值之和。

发布后仍可编辑实例类型、标题、说明、状态、截止时间、选题方式、题目和计分设置。结构更新只作用于后续填写：Questra 会保留已有答卷引用的旧题目快照和历史分数，并在数据页面与导出中以“历史”列继续展示。设置截止时间后，过期实例拒绝新提交；编辑已过期实例时会强制关闭，回收状态暂时不可修改，只有把截止时间改到未来才可重新选择“回收中”或“已关闭”。

## 5. 填写者体验

将 `/s/<问卷 ID>` 发送给填写者。公开读取和提交不需要管理员 Token；页面只收到填写所需的题目字段，考试标准答案不会通过公开接口下发。提交前服务器会再次校验必填项、选项和文本长度，并在考试中完成判分。

提交成功后，普通问卷显示感谢信息，考试返回得分和满分。关闭或过期的实例返回不可提交状态。

## 6. 查看和导出答卷

在问卷的“数据”页面查看答卷数量、提交时间、逐题答案和考试成绩。CSV 适合 Excel，JSON 适合二次处理；两种导出都需要管理员认证。在线导出不会修改答卷。

建议在分享链接前先用浏览器完成一次测试提交，确认题目顺序、必填规则、截止时间和考试得分符合预期。

## 7. 站点设置

“设置”分为四类：

- **站点设置**：保留该分类作为设置导航入口；站点名称、站点图标和标识等实际选项已集中到“个性化”页面。
- **个性化**：调整站点名称、站点图标、标识字符、标识背景色和界面主题色。站点图标可使用 HTTPS 地址、站内路径、上传图片或 Emoji，图片上传限制为 1 MB；未设置或清空图标时使用 "📜"。默认以标识字符显示站点标识，勾选“使用站点图标”后，图标会覆盖标识字符。页面底部可以在二次确认后恢复全部个性化设置。
- **更新**：位于设置分类最下方。npm 或 GitHub Release 全局安装的版本会先验证当前版本是否存在于正式 Releases，再显示最新版本和落后数量，并可在二次确认后使用 npm 安装。源码构建版和不在正式 Release 列表中的版本会禁用在线更新，并引导用户前往源码仓库或重新安装最新正式版。安装完成仍需重启服务。
- **账号安全**：修改管理员昵称、登录账号或密码。只有一组管理员账户；改变账号或密码后需要重新登录。

更详细的认证方式、管理接口和自动化调用见 [HTTP API](api.md)；环境变量、备份和进程托管见 [安装与部署](installation.md)。
