# Questra 方案书

本目录保存功能开发和架构调整的执行方案。方案书以当前代码为依据，记录目标、范围、设计决定、实施步骤、验收条件和执行状态；面向最终用户的稳定说明仍应归入 `README.md` 或对应专题文档。

## 状态约定

- **草案**：目标或关键决定仍可能调整，尚未开始实现。
- **已确认**：范围和主要设计已确定，可以开始实现。
- **实施中**：正在按方案修改代码，步骤状态应随进度更新。
- **已完成**：实现、必要验证和正式文档归类均已完成。
- **已搁置**：当前不再实施，并在方案中说明原因。
